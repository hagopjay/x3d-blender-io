# Gallery 01: pendulum wave

**Idea.** Fifteen pendulums, fifteen clocks. Pendulum *i* swings 6+i times in 12 s, so the row fans out into travelling
waves, braids, then snaps back into one line every 12 s. Bobs glow brighter at the ends of their swing and are
coloured round the rainbow.

**Graph.** 15 looping TimeSensors (`Clock0..14`, `cycleInterval = 12/(6+i)`), each into an OrientationInterpolator
(a 24-step sine, ±0.62 rad, about X3D z) → the pivot Transform's `rotation`, and into a ColorInterpolator → the bob's
`emissiveColor`. Clicking the beam (TouchSensor `Restart`) routes `touchTime` to every clock's `stopTime`, and starts a
0.05 s TimeSensor `Gap`; when `Gap` ends, BooleanFilter `GapDone` (`inputNegate`) → TimeTrigger `Again` → every clock's
`startTime`. 79 nodes, 93 ROUTEs. Generated by `build.py`.

**Play.** Import X3D with "Behaviour graph" on, press Play. Watch the wave; click the beam to restart every clock in
phase. Esc stops and restores.

## Findings for Loom

1. **Restarting a looping TimeSensor needs stop, then start.** `set_startTime` on an active TimeSensor is ignored
   (X3D 8.4.1; the simulator follows it), so `touchTime → startTime` alone does nothing. The Gap pattern above
   works in the simulator.
2. **TimeTrigger fires on `true` only.** `BooleanFilter.inputFalse` carries `false` and does not trigger it; use
   `inputNegate`.
3. **Eye-test acts must pick the live object.** The eye test imports each world more than once, so Blender suffixes
   names (`Pivot3`, `Pivot3.002`) and `scene.objects.get("Pivot3")` can return a stale copy. The act picks the
   highest suffix.
4. The graph reads X3D z-rotation as Blender y: signed angle is `2*atan2(q.y, q.w)`.
